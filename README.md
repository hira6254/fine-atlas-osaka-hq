# ファインアトラス｜大阪本社 外食・寿司・海鮮居酒屋・和食チェーン本部 テレアポ営業コンパス（厳選62社）

株式会社ファインアトラス（ファインスタッフ × 対馬水産）向けに構築した、**大阪府内に本社・本部を置く外食・寿司・海鮮居酒屋・和食チェーン運営会社（厳選62社・実在電話番号＆本社所在地検証済）** の本部バイヤー攻略用WebコンパスおよびExcel営業台帳です。

## 主な収録コンテンツ
1. **Excel営業台帳（4シート構成）**: `ファインアトラス_大阪本社_外食・寿司・海鮮居酒屋チェーン本部_テレアポ営業台帳.xlsx`
   - `ダッシュボード_大阪本社攻略`（優先ランク別・本社エリア別・架電進捗ステータス別の自動集計 `COUNTIF`/`COUNTA`）
   - `大阪本社_チェーン本部架電リスト`（全62社の本社電話番号・住所・代表者・店舗規模・展開ブランド・狙うべき部署・推奨5商材・受付突破＆バイヤー商談トーク・進捗プルダウン入力規則）
   - `本部バイヤー専用_受付突破＆商談トーク集`（代表電話から商品部バイヤーへの取次ぎスクリプト＋反論処理6選）
   - `ファインアトラス商材＆チェーン提案規格表`（無添加炊き上げ煮穴子・活〆真穴子フィレ・鱗付き赤甘鯛フィレ・炙りのどぐろ・皮むき剣先イカ柵＋公式お試しセット税込10,000円）
2. **スマホ・PC対応 1タップ架電Webコンパス**: `index.html` / `app.js` / `styles.css` / `data.js`
   - 文字サイズ3段階切替（標準・大・特大）
   - スマホ・PCからの1タップ発信（`tel:`）および大文字トークカンペモーダル（受付突破 ⇄ バイヤー接続 ⇄ 切り返し6選）
   - 進捗ステータス＆バイヤーメモのブラウザ自動保存（`localStorage`）およびCSVエクスポート機能
